# セブ島から、四半期ごとに進捗を晒すことにしました 【2026年Q1振り返り&Q2目標設定】

## はじめに

はじめまして、note初投稿です。

「四半期ごとに目標を立てて振り返る」を、2026年からゆるく自分の中でやっているのですが、せっかくならパブリックな場所に置いてみようと思い、noteを始めることにしました。今後、Q末ごとに同じフォーマットで振り返りを書いていく予定です。
進捗が芳しくなくても晒す、という方向でやっていきます (自戒を込めて)。

第1弾として、**2026年Q1 (1〜3月) の振り返り** と **Q2 (4〜6月) の目標設定** をまとめます。

## 軽く自己紹介

本格的な自己紹介記事を書く予定はないので、ここで軽く触れさせてください 🌴

- **セブ島在住** (2019年5月から移住、もうすぐ7年目)
- **日系IT企業のブリッジSE** として、顧客折衝・開発推進 (マネジメント / リード) を担当。**AWSインフラ領域** が一番の強み
- **副業**: 会社経営をしている友人から開発案件を請けて、**AIエージェントベースの実装** に慣れるべく開発業務をしています

軸は「**セブ島 × 英語 × AWS × AI**」です。
このクロスで日々もがいているエンジニアの記録、くらいのテンションで読んでもらえると嬉しいです。

## 2026年Q1の振り返り

年初に立てていた目標はこちらの4つでした。

| 目標                    | 結果                 |
| ----------------------- | -------------------- |
| Web開発ロードマップ完走 | ❌ (意図的にやめた)  |
| AWS認定 (MLA) 取得      | ✅ MLA/MLSの2冠取得  |
| TOEIC800点取得          | 🟡 5/16に受験予定    |
| 週4筋トレ               | ✅ ほぼ達成 (週3〜4) |

順番に振り返ります。

### ① Web開発ロードマップ完走 → 意図的にやめた

これ、年始の自分はやる気満々だったんですが、Q1の途中で **「やらない」と決めました**。
理由はシンプルで、2026年のいまWebフロント/バックの基礎体力を積み増すよりも、**Claude CodeをはじめとするAIエージェントを使い倒せること** のほうが、自分の市場価値に直結すると判断したからです。
副業ではAIエージェントを使った開発でちゃんと価値を出せている手応えがあって、ロードマップを律儀に走るより、目の前の実プロジェクトでエージェントを回したほうが、学びの密度が圧倒的に高いんですよね。

「目標を立てたからやる」より、「目標は仮説、明らかに筋が違うなら書き換える」のほうが健全。
これがQ1最大の収穫かもしれません 🤔

### ② AWS認定 → MLA/MLSの2冠 🏆

ここは想定以上に進んで、**MLA (Machine Learning Engineer - Associate) と MLS (Machine Learning Specialty) の2つに合格** できました。

ML系の資格を立て続けに取れたことで、本業・副業のAI関連プロジェクトでの会話の解像度が一段上がった実感があります。「専門用語で殴られたときに、ちゃんと殴り返せるようになった」という感じ。
一方で、AIの市場価値の重心は明らかに生成AI寄りに動いています。今回取得したMLA/MLSは「生成AIを使いこなすための土台」として効いてくる、という捉え方をしていて、Q2はこの土台の上に生成AI領域を乗せていく動きをします。

### ③ TOEIC800点 → 5/16に受験予定

Q1中の本番受験はせず、**5/16に予約済み**。
本業・副業・資格学習の負荷が重なったので、本番をねじ込むより準備に充てたほうが結果的に高得点を狙える、という判断です。
勉強自体はちゃんと続いているので、ルーティン化はできていると見ていいはず…! (と自分に言い聞かせる)

### ④ 週4筋トレ → ほぼ達成 💪

週3〜4でジムに行けたので、ほぼ目標通り。
セブ島はジムが安いし、年中Tシャツ短パンで通えるのが地味に最強です。ここはもう「歯磨きと同じ」レベルで生活に組み込めていて、意志力をほぼ使わずに続けられています。

## Q1総評

- **「やめる判断ができた」のが一番の収穫** (Web開発ロードマップ)
- AWS資格は当初想定より深く取れた
- 英語と筋トレは仕組み化に成功

達成率で見るより、「四半期の終わりに自分の立ち位置がどれだけ良くなったか」で評価すると、Q1は結構満足度が高い四半期でした 🎉

## 2026年Q2の目標

Q1の流れを踏まえて、Q2のテーマは **「作って、出して、知ってもらう」** にします。
資格・インプット中心だったQ1から、**アウトプット中心** にギアチェンジするイメージです。

### 🎯 メイン目標①: 個人開発でアプリを1本リリースする

Q2の最重要目標はこれ。

Claude Codeをはじめとするエージェントが揃った2026年の今、**個人でも本気でプロダクトを世に出せる時代** です。「自分が作ったものをユーザーが触る」「あわよくば収益化する」という体験は、本業だけをやっていたら絶対に手に入らない種類の経験値だと信じてます。

副業で得たエージェント運用のノウハウを、自分のプロダクトに全部突っ込みます。
**完璧主義で抱え込むより、雑でもいいから出す**。リリースを目的に置く、というのが大事。

### 🎯 メイン目標②: X/Zennでの情報発信

ポジショニングは前述のとおり **「セブ島 × 英語 × AWS × AI」**。
日本のエンジニア界隈で、このクロスはまあまあレア寄りで、自分の体験そのものがコンテンツになりやすい領域だと思っています。

KPIは以下に置きます。

- Zennまたはnote記事: **隔週1本** (本業・副業・個人開発で得た知見ベース)
- Xポスト: **週3〜5ポスト** くらいのペース
- Q2通して **Xフォロワー100人突破**

数字を追うのが目的ではないですが、可視化しないと続かないタイプなので、あえて定量で置きます。
このnoteもその一環、ということで 📝

### 💪 余力があったら挑戦したいこと: AWS SOA-C03 (CloudOps Engineer - Associate)

AWSの資格は一旦お休みにしようと思っていたのですが、本業とのシナジーがあること、**AI時代だからこそSysOps/DevOpsの領域を握れる人間は強い** と考え直しました。
SOA-C03は2025年9月にSysOps Administrator - AssociateからCloudOps Engineer - Associateにリネームされた資格で、ただのリブランドではなく、コンテナ・IaC・マルチアカウント設計といった現代の運用テーマが新たに範囲入りしています。AIエージェントが書いたコードを「ちゃんと運用に乗せる」スキルセットそのものなので、自分の進む方向と重なる。
あくまで余力があれば、ですが、6月後半あたりに受験できるとペース配分的に綺麗かなと考えています。

### 🔁 継続するルーティン

ここはもう仕組み化済みなので、変えずに続けます。

- **TOEIC学習** (5/16の本番に向けてラストスパート)
  - 受験後も英語力向上・維持のために学習は継続
- **週4筋トレ**

## Q2の優先順位: 迷ったときに何を選ぶか

複数の目標を並走させると、必ず時間の取り合いが起こります。
そのとき迷わないように、優先順位を先に決めておきます。

1. **個人開発 (リリースに直結する作業)**
2. **情報発信 (書く・出す)**
3. **TOEIC** (5/16まで)
4. **筋トレ** (健康投資、ここを削ると全部崩れる)
5. (余力があれば) **AWS SOA-C03**

「資格学習を理由に個人開発が止まる」のは本末転倒なので、上から順に守る、と先に決めておきます。
